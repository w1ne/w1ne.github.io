# FlowStun proposal microsite

Static website built from the FlowStun mockup and proposal draft.

## Open locally

Open `index.html` in any modern browser. No build step or internet connection is required.

## Deploy

Upload the entire `flowstun_site` folder to any static host: GitHub Pages, Netlify, Vercel, Cloudflare Pages, or a normal web server. The entry file is `index.html`.

## Included files

- `index.html` — website structure.
- `styles.css` — visual design and responsive layout.
- `script.js` — tabs, scroll progress, risk filters, budget toggle, copy-summary button.
- `docs/FlowStun_LOI_v2_FINAL.docx` — current LOI draft.
- `docs/FlowStun_Roast_QA_v2_FINAL.docx` — QA / roast memo.
- `assets/mockup-reference.png` — original visual mockup reference.

## Notes

The website is best used as a reviewer-facing companion to the formal LOI unless the funder explicitly allows alternate formats.
